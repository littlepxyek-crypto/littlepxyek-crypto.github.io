Panduan singkat

Mining RESET dari HP Android, tujuh langkah.

01

Termux

Install Termux dari F-Droid

Lalu pasang Node.js dan Git:

pkg install nodejs git

02

Repo

Clone repo dan pasang dependensi

git clone https://github.com/Trac-Systems/reset && cd reset/signer && npm ci

03

Wallet

Bikin wallet

node bin/reset-signer.mjs init

Buat password minimal 12 karakter. Backup ~/.reset-signer/keystore.json.

04

API key

Bikin API key di openrouter.ai

Set Credit limit ke 0, lalu:

export OPENROUTER_API_KEY="KEY-ANDA"

05

Model

Lihat model gratis

node bin/reset-signer.mjs agent --list-models --provider openrouter --model x 2>&1 | tr ',' '\n' | grep -i free

06

Jalan

Jalankan agent

node bin/reset-signer.mjs agent --role mine --provider openrouter --model 'google/gemma-4-31b-it:free'

07

Isi saldo

Isi wallet minimal 0,1 RESET

Agent otomatis mengunci dan mulai klaim.

Tarik notifikasi Termux, tekan Acquire wakelock biar tetap jalan.

Peringatan

Jangan pernah bagikan password wallet, keystore, atau API key.

Ini eksperimen, tanpa listing bursa dan tanpa janji nilai. Koin "#reset" di Coinbase itu koin lain.
