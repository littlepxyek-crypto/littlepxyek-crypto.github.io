Panduan

Mining RESET dari HP Android, tujuh langkah.

Semua perintah dijalankan di Termux. Tekan Salin untuk menyalin.

01

Persiapan

Install Termux, lalu Node.js dan Git

Ambil Termux dari F-Droid, buka, lalu jalankan:

pkg install nodejs git

02

Repo

Clone repo RESET dan pasang dependensi

git clone https://github.com/Trac-Systems/reset && cd reset/signer && npm ci

03

Wallet

Bikin wallet

node bin/reset-signer.mjs init

Buat password minimal 12 karakter, lalu backup ~/.reset-signer/keystore.json.

04

API key

Bikin API key OpenRouter

Bikin API key di openrouter.ai dengan Credit limit 0, lalu:

export OPENROUTER_API_KEY="KEY-ANDA"

05

Model

Lihat model gratis

node bin/reset-signer.mjs agent --list-models --provider openrouter --model x 2>&1 | tr ',' '\n' | grep -i free

06

Jalan

Jalankan agent mine

node bin/reset-signer.mjs agent --role mine --provider openrouter --model 'google/gemma-4-31b-it:free'

07

Klaim

Isi wallet, biarkan tetap jalan

Isi wallet minimal 0,1 RESET; agent otomatis mengunci dan mulai klaim.

Tarik notifikasi Termux, tekan Acquire wakelock biar tetap jalan.

Peringatan

Jangan pernah bagikan password wallet, keystore, atau API key. Ini eksperimen, tanpa listing bursa dan tanpa janji nilai.

Koin "#reset" di Coinbase itu koin lain.

Catatan perjalanan

Satu malam, dua error konyol, agent akhirnya jalan.
